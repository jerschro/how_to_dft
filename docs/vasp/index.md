# VASP <a href="https://www.vasp.at/wiki/" class="md-button small-button">VASP Wiki</a>

This is the homepage for containing everything to do with VASP. 

If you want more detailed explanations you can check out the [VASP Forum](https://www.vasp.at/forum/) or [VASP Wiki](https://www.vasp.at/wiki/). To use VASP on the TTU HPCC, it is important you are on the our research group's VASP License, as VASP is a proprietary software.

## Input Files

* [INCAR](INCAR.md) - Main input file for VASP.
* [POSCAR](POSCAR.md) - Geometry for calculation.
* [POTCAR](POTCAR.md) - Potentials for system.
* [KPOINTS](KPOINTS.md) - File defining the KPOINTS for the calculation.
* Slurm Script - Shell script that runs VASP on the HPC.

## Output Files

* [OUTCAR](OUTCAR.md) - Main output file for VASP.
* Many Others... Check the VASP Wiki for more info [Here](https://www.vasp.at/wiki/index.php/Category:Output_files).


## Phonopy

Phonopy is a program that we use combined with VASP to calculate the phonon frequencies of the optimized geometry. Navigate to the [Phonopy page](phonopy.md) or check out their documentation link: [https://phonopy.github.io/phonopy/](https://phonopy.github.io/phonopy/).

## VASPKIT

VASPKIT is a program that can be used to postprocess a VASP calculation. Documentation link: [https://vaspkit.com/](https://vaspkit.com/)
